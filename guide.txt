I want to build an enterprise-grade cybersecurity platform called ZeroTrustNet.

This is NOT a basic anomaly detection project.

It should simulate a real Zero Trust Security Platform used by organizations to monitor employees continuously after login and help Security Operations Center (SOC) analysts detect insider threats.

The application must look and behave like a commercial cybersecurity product.

===========================================================
PROJECT GOAL
===========================================================

Every employee in the organization must use ZeroTrustNet before starting daily work.

After successful authentication, every user session should be continuously monitored.

The system should collect real events generated inside the application instead of creating random or fake values.

Every employee action should be stored as an audit event.

The administrator must have a live dashboard showing all employee activities.

The platform should continuously calculate the employee's risk level based on behavior.

No random values.

No dummy risk scores.

Every decision must be explainable.

===========================================================

2. Local Outlier Factor (LOF)
Purpose:
Find local behavioural outliers.

3. One-Class SVM
Purpose:
Detect unknown abnormal behaviour.

4. DBSCAN
Purpose:
Discover unusual behavioural clusters.

5. Rule-Based Risk Engine
Purpose:
Apply transparent organizational security policies.

6. Behaviour Baseline Engine
Purpose:
Compare current behaviour against the employee's historical behaviour instead of comparing all employees together.

The final risk assessment should combine ML outputs and policy evaluation.

Use actual model outputs and explain how the final decision is derived.
